Icons are from [Lucide](https://github.com/lucide-icons/lucide), downloaded on
2026-10-03. The original SVGs and upstream license are included here.
The unplug and Wi-Fi-off icons were added on 2026-10-04.

PNG exports use the same outlines in EtherDrop's two accent colors and neutral
text colors. Tkinter loads these offline exports; no SVG renderer or additional
runtime dependency is required. All assets are bundled inside EtherDrop.exe.
